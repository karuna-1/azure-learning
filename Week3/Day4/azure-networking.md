# Day 4 – Azure Networking

## 1. Virtual Network (VNet)
- A private network in Azure.
- Allows Azure resources to communicate securely.
- Provides network isolation.

## 2. Public IP Address
- Used for communication over the internet.
- Example: Users accessing a public website.

## 3. Private IP Address
- Used for communication within private networks.
- Not directly accessible from the public internet.
- Example: API server communicating with a database.

## 4. Network Security Group (NSG)
- Controls incoming and outgoing network traffic.
- Uses security rules to allow or deny traffic.

### Common Network Ports
- 22: SSH
- 80: HTTP
- 443: HTTPS
- 3306: MySQL

## 5. DNS (Domain Name System)
- Translates domain names into IP addresses.
- Example: Resolves google.com to an IP address.

## Key Takeaway
Azure networking helps connect cloud resources securely and control network access.
