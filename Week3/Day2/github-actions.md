# Day 2 – GitHub Actions

## YAML
A human-readable configuration format.

## YAML Concepts
- Key-value pairs
- Indentation
- Lists

## GitHub Actions
Automates software development workflows.

## Workflow Components
- Workflow: Complete automation process.
- Trigger: Determines when workflow runs.
- Job: Group of tasks.
- Step: Individual task.
- Runner: Machine executing jobs.

## Common Triggers
- push
- pull_request
- workflow_dispatch

## First Workflow
Created hello.yml.

- Trigger: push
- Job: hello
- Runner: ubuntu-latest
- Step: Print Hello, DevOps!

## Result
Successfully executed my first GitHub Actions workflow.
