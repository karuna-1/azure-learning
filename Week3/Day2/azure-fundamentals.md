# Day 2 – Azure Fundamentals

## Azure Region
A geographical area containing Azure data centers.

## Availability Zones
Physically separate locations within an Azure region.
They help improve application availability.

## Resource Groups
Logical containers used to organize Azure resources.

## Azure Subscription
A boundary for billing, resource management and access control.

## Important Differences
- Region: Geographical location.
- Availability Zone: Separate physical location.
- Resource Group: Organizes resources.
- Subscription: Billing and management boundary.
