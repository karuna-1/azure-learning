# Day 1 – CI/CD Fundamentals

## What is CI/CD?
CI/CD automates software testing, building and deployment.

## Continuous Integration (CI)
- Automatically integrates code changes.
- Runs automated tests.
- Detects errors early.

## Continuous Delivery
- Automatically tests and prepares applications for release.
- Production deployment may require manual approval.

## Continuous Deployment
- Automatically deploys successful changes to production.

## GitHub Actions
GitHub Actions automates workflows directly inside GitHub.

### Example Workflow
1. Developer pushes code.
2. GitHub Actions starts.
3. Automated tests run.
4. Docker image is built.
5. Application is deployed.
