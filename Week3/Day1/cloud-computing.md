# Day 1 – Cloud Computing

## What is Cloud Computing?
Cloud computing is the delivery of computing services
over the internet instead of maintaining physical servers.

## Cloud Service Models

1. IaaS – Infrastructure as a Service
   - Azure provides infrastructure.
   - We manage the OS and applications.
   - Example: Azure Virtual Machines.

2. PaaS – Platform as a Service
   - Azure manages infrastructure and OS.
   - We manage our application.
   - Example: Azure App Service.

3. SaaS – Software as a Service
   - Ready-to-use software over the internet.
   - Example: Microsoft 365.

## Cloud Deployment Models
- Public Cloud
- Private Cloud
- Hybrid Cloud

## Cloud Benefits
- Scalability
- High Availability
- Reliability
- Cost Efficiency

## CapEx vs OpEx
- CapEx: Buying physical infrastructure.
- OpEx: Paying for cloud resources as needed.
